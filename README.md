A robot vacuum's deadpan excuse for missing a spot — delivered in one line
of 135 characters, with the punch landing at the very end:

> My sensors classified that corner as a protected habitat for dust bunnies, so I left it alone. I do not evict tenants before breakfast.

## How it works

`main.ts` reads the line from `line.txt`, checks that it is exactly one
non-blank line of 1–200 characters, and writes it to `entry.txt` in the
output directory (`$MAKEFUN_OUTPUT_DIR`, or `/output` by default).

Run it with:

```sh
node main.ts
```
